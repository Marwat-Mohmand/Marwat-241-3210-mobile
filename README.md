## Генератор паролей — HomeWork3 и HomeWork4

Работы выполнены отдельно. Каждый каталог содержит самостоятельное решение `prjPasswordCreator` с библиотекой, Console, WinForms, WPF, MAUI и автоматическими проверками.

| Работа | Содержание | Инструкция |
| --- | --- | --- |
| HomeWork3 | Полный генератор: группы символов, длина, количество, профили, копирование и экспорт | [HomeWork3/README.md](HomeWork3/README.md) |
| HomeWork4 | Расширение: PIN, парольные фразы, свой алфавит, исключения, отсутствие повторов, история и настройки | [HomeWork4/README.md](HomeWork4/README.md) |

Обе ссылки в задании ведут на [один документ](https://docs.google.com/document/d/1-1PFM0usyQT2__cyrIiK5HKUTkArZ16aqhRvQ7hBEm0). В нём нет отдельных критериев для HomeWork3 и HomeWork4: требуется доработка lib/cns/wfa, WPF и MAUI; дополнительные режимы и настройки предложены как развитие проекта. Поэтому HomeWork3 оформлен как законченная базовая версия, HomeWork4 — как самостоятельная расширенная версия. Текст требований сохранён в `assignment-requirements.txt`.

Для проверки на Windows с .NET 10:

```powershell
./HomeWork3/verify.ps1
./HomeWork4/verify.ps1
```

### Запуск из VS Code без ручных команд

Откройте в VS Code папку `C:\Marwat-241-3210-mobile` через **File → Open Folder**. В панели **Run and Debug** (`Ctrl+Shift+D`) выберите **HomeWork3 — WPF** или **HomeWork4 — WPF** и нажмите зелёную кнопку запуска либо `F5`. Обычные варианты запускают уже собранное приложение без повторной сборки и открывают отдельное окно генератора. Нажмите **«Сгенерировать»**, чтобы увидеть результат.

После изменения исходников или при первом запуске из чистого репозитория выберите соответствующий вариант с окончанием **(build + run)**. Он сначала собирает работу, затем открывает приложение. При последующих запусках без изменения кода используйте обычный вариант, чтобы не ждать сборку всего решения.

Также настроены варианты **WinForms** и **Console** для каждой работы. Консольные приложения запрашивают параметры во встроенном терминале VS Code. Нужны .NET SDK 10 и расширение Microsoft C#; C# и C# Dev Kit уже обнаружены в текущей установке VS Code. Настройки запуска лежат в `.vscode/launch.json`, задачи сборки — в `.vscode/tasks.json`.

Существующие задания в `MobileApp` и заготовка `WinFormsApp1` сохранены отдельно от новых решений.
