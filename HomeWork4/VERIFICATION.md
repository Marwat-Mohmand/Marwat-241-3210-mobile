В `verify.ps1` предусмотрена последовательная Desktop-сборка без сервера компиляции, проверки workloads и внешних NuGet-источников. Проверки сохранения настроек используют временный JSON рядом с тестовой сборкой и удаляют его после проверки.

MAUI реализован для Android/Windows с точками входа iOS/Mac Catalyst; его компиляция и запуск **не подтверждены**. Проверка XML не проверяет корректность MAUI-привязок или платформенных SDK. Локальный SDK в сообщении `NETSDK1147` указал недостающий компонент `maui-tizen`; команды установки обычного MAUI-окружения и последующей сборки приведены в README. Глобальные workloads не устанавливались.
